## Document Structure

Each chapter summary follows the **concept-node** format optimized for LLM-driven node generation:

### Per Chapter:
- **Overview** (core insight and context)
- **Section-by-section breakdowns**:
  - Key concepts (narrative)
  - Concept nodes (structured: id, title, formula, principle, vars, causal, limits, misconceptions, prereqs)
- **Summary of core principles**
- **Key formulas** (quick reference table)
- **Limits, edge cases, and idealizations**
- **Misconceptions and instructional traps**
- **Connections to earlier/later chapters**
- **Laboratory and computational topics**

### Concept Node Structure:
- **id**: kebab-case identifier
- **title**: Human-readable name
- **formula**: Mathematical expression (if applicable)
- **principle**: Core idea in prose
- **vars**: Variables, units, meaning
- **causal**: Relationship type (cause → effect)
- **limits**: Boundary conditions, where formula breaks
- **misconceptions**: Common instructional traps
- **prereqs**: Knowledge prerequisites (graph connections)
