# ABOUT ATLAS

## Vision

Atlas is the spiritual successor to HyperPhysics: a structured, explorable map of physics knowledge. Where HyperPhysics uses static image maps and text, Atlas uses an interactive node graph with rendered equations, variable breakdowns, and embedded visual scenes (PhET simulations, custom widgets, video). The experience is closer to exploration than reference lookup - you enter a domain, follow connections, and go deeper than you meant to.

**Long-term north star (out of scope for Phase 1):** Student progress tracking across the graph; AI agent using the node graph as a structured knowledge base to guide students through lab exercises; integration surface for companion platforms.
